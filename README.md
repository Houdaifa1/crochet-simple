# Crochet Simple

Crochet patterns, a studio journal, and a homepage where one yarn line draws seven pieces as
you scroll.

## Requirements

- Node.js 24 (`nvm use`)
- pnpm 12

## Getting started

```bash
pnpm install
pnpm check:assets
```

Run, build, publish and backup instructions are added here as each part of the site is
built. The approved plan is in [docs/plan.md](docs/plan.md); rules for contributors are in
[CLAUDE.md](CLAUDE.md) and [AGENTS.md](AGENTS.md).
